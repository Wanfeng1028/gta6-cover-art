Neon Dusk Cover Maker turns any photo into a multi-panel GTA-style poster: pick a layout, drop a photo into each panel, crop and position it, write a bold outlined title, choose a sunset, neon or dusk colour grade, and export a PNG in 1080×1080, 1080×1350 or 1920×1080. Everything runs offline in the browser; photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.

Sunset Cover Studio turns your own photos into a multi-panel GTA 6-style poster — Vice City sunset grade, bold outlined title lettering, per-panel crop and position — and exports it as a PNG in 1080×1080, 1080×1350 or 1920×1080. It runs fully offline in the browser; photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080, add a photo, pick a panel, crop it with the sliders, type your title, and hit Export PNG.
